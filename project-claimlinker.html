Case Study: ClaimLinker

Developed an innovative NLP system that automatically links textual claims to a knowledge graph of fact-checked information, helping identify and verify claims using advanced similarity measures and search technologies for automated fact-checking.

Research Project

Field: Natural Language Processing

Institution: University Research

Type: Academic Research

The project aimed to automate the fact-checking process by linking claims to a database of previously verified information. By using multiple similarity measures and semantic search, the system helps researchers and fact-checkers quickly identify related claims.

Project Requirements

  • Unsupervised claim detection and extraction from text
  • Multiple textual similarity measures for comprehensive matching
  • Elasticsearch-powered semantic search capabilities
  • Knowledge graph integration for fact verification
  • Scalable architecture for large claim databases

Project Overview

ClaimLinker addresses the challenge of identifying whether a claim has been previously fact-checked. With the exponential growth of misinformation online, fact-checkers often duplicate efforts by verifying the same claims multiple times. This system helps them quickly find existing fact-checks and focus on new, unverified claims.

The system processes claims through multiple similarity algorithms and combines their scores to produce accurate matches, even when claims are phrased differently or use different vocabulary while expressing the same core assertion.

The Challenge

The main challenges included handling semantic similarity when claims are expressed in different ways, dealing with incomplete or vague claims, and achieving high accuracy while maintaining fast query response times for large databases.

Additionally, the system needed to work in an unsupervised manner without requiring labeled training data, and be flexible enough to handle claims across different domains and topics without domain-specific tuning.

The Approach & Solution

Built using Java with extensive NLP libraries for text processing. The system employs a multi-layered approach:

  • Preprocessing Layer: Text cleaning, tokenization, and entity extraction
  • Similarity Computation: Eight different similarity measures including cosine, Jaccard, Levenshtein, and semantic embeddings
  • Search Layer: Elasticsearch for fast full-text and semantic search
  • Ranking Layer: Custom algorithm combining similarity scores with search relevance
  • Knowledge Graph: Neo4j for storing and querying fact-checked claims with relationships

The similarity measures are carefully weighted and combined. Vector-based methods (Word2Vec, TF-IDF) capture semantic meaning, while character and token-based methods (Levenshtein, Jaccard) handle lexical similarity. The final ranking uses a weighted average of all scores combined with Elasticsearch's BM25 relevance score.

The system successfully demonstrated that automated claim linking is feasible with high accuracy using unsupervised methods. Fact-checkers can now quickly search for similar claims before starting verification work, reducing duplication and accelerating the fact-checking process.

The research contributed to the academic understanding of automated fact-checking and has potential applications in journalism, social media platforms, and information verification systems. The multi-similarity approach proved more robust than single-method systems.
